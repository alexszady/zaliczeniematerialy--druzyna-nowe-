# Aktorzy systemu

## Użytkownik
Osoba korzystająca z publicznego widoku aplikacji. Może:
- przeglądać listę zawodników;
- przeglądać statystyki drużyny i zawodników;
- przeglądać terminarz oraz wyniki meczów;
- przeglądać tabelę strzelców.

## Administrator / Trener
Osoba odpowiedzialna za aktualność danych. Oprócz funkcji użytkownika może:
- dodawać zawodników;
- aktualizować dane zawodników;
- usuwać zawodników;
- zarządzać wpisami meczów (dodawanie, edycja i usuwanie — zgodnie z zakresem API).

## System zewnętrzny
Nie zidentyfikowano zewnętrznego dostawcy danych. Aplikacja komunikuje się z własnym API Express i bazą SQLite.
