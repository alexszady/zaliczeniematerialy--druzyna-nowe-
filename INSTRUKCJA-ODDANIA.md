# Lista kontrolna przed oddaniem

- [ ] Uzupełnij dane autora, nazwę przedmiotu i datę, jeśli wymaga tego prowadzący.
- [ ] Uruchom `npm install`, a następnie `npm start`.
- [ ] Otwórz `http://localhost:3000` i sprawdź wszystkie sekcje.
- [ ] Przetestuj dodawanie i usuwanie zawodnika oraz meczu.
- [ ] Sprawdź statystyki, tabelę strzelców i terminarz.
- [ ] Przetestuj endpointy PUT zawodnika i meczu przez klienta API.
- [ ] Wykonaj testy z `docs/Dokumentacja_projektu.pdf` i wpisz rzeczywiste wyniki.
- [ ] Otwórz diagram ERD i sprawdź czytelność nazw pól oraz kluczy.
- [ ] Sprawdź wszystkie diagramy PNG i ich źródła DOT.
- [ ] Upewnij się, że prowadzący akceptuje format dokumentacji.
- [ ] Nie dodawaj `node_modules/` ani `database.db` do repozytorium.

## Istotne
Dokumentacja opisuje aktualny kod. Edycja rekordów jest dostępna przez API, ale nie przez interfejs WWW. Tabele `players` i `matches` nie są połączone relacją. Nie wpisuj fikcyjnych wyników testów — uzupełnij je po wykonaniu.
