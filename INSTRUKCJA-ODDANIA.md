# Lista kontrolna przed oddaniem

- [ ] Uzupełnij dane autora i przedmiotu, jeśli prowadzący tego wymaga.
- [ ] Wykonaj `npm install` oraz `npm start`.
- [ ] Otwórz `http://localhost:3000` i sprawdź wszystkie cztery sekcje.
- [ ] Ręcznie wykonaj testy z `docs/testy.md` i uzupełnij wyniki.
- [ ] Otwórz PNG diagramów i sprawdź czytelność.
- [ ] Sprawdź diagramy sekwencji w plikach Mermaid w `diagramy/sekwencje/` (GitHub renderuje Mermaid w Markdown).
- [ ] Upewnij się, że prowadzący akceptuje zakres i format dokumentacji.
- [ ] Nie dodawaj `node_modules/` ani `database.db` do repozytorium.

## Istotne ograniczenie

Edycja zawodników i meczów jest dostępna przez endpointy PUT backendu, ale nie przez interfejs WWW. Dokumentacja i diagramy opisują to rozróżnienie wprost.
