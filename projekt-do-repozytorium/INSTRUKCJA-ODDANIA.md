# Lista kontrolna przed oddaniem

- [ ] Wpisać imię i nazwisko autora oraz nazwę przedmiotu, jeśli prowadzący wymaga ich na stronie tytułowej.
- [ ] Uruchomić `npm install`, a następnie `npm start`.
- [ ] Sprawdzić działanie strony pod adresem `http://localhost:3000`.
- [ ] Przetestować listę zawodników, statystyki, terminarz i tabelę strzelców.
- [ ] Przetestować endpointy API dodawania, edycji i usuwania.
- [ ] Otworzyć diagramy PNG i sprawdzić czytelność napisów.
- [ ] Upewnić się, że prowadzący akceptuje format dokumentacji i diagramów.

## Ważne

Diagramy i dokumentacja przedstawiają zakres funkcjonalny projektu. Jeśli w interfejsie użytkownika brakuje formularza edycji, nie należy opisywać edycji jako dostępnej z poziomu UI — edycja jest obecnie udostępniona przez API. Podobnie, przykładowe dane w bazie mają charakter demonstracyjny.
