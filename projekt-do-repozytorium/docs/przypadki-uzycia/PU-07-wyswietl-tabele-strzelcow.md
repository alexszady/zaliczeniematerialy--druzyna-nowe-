# Wyświetl tabelę strzelców

- **ID:** PU_07_WYSWIETL_TABELE_STRZELCOW
- **Aktorzy:** Użytkownik, Administrator / Trener
- **Warunki wstępne:** Dane zawodników są dostępne.

## Scenariusz podstawowy
1. Aktor otwiera tabelę strzelców.\n2. Interfejs pobiera listę zawodników.\n3. Zawodnicy są sortowani malejąco według liczby goli.\n4. System wyświetla miejsce, nazwisko, pozycję, występy, asysty i gole.

## Scenariusze alternatywne / błędy
Przy pustej liście tabela nie zawiera pozycji strzelców.

## Warunek końcowy
Dane zostały przedstawione lub zmodyfikowane zgodnie z wybraną operacją.
